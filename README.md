# Hookra

> Hookra — From hooks to results.

Hookra is a **mobile SaaS platform** designed for **marketing agencies and digital marketing teams** to centralize and automate the social media content workflow. The platform leverages **AI-assisted content generation**, **team collaboration**, **client approval flows**, and **performance analytics** to help agencies move faster from idea to published content while reducing operational friction. The name is derived from the concept of a **"hook"**, the most important element of short-form content that captures attention.

[Learn more about the product context and vision](docs/PRODUCT.md)

## Technology Stack

- **Flutter** — mobile app
- **Next.js** — landing page and web dashboard
- **Supabase** — backend + database
- **GenAI APIs** — content generation
- **Meta / TikTok APIs** — potential integrations

## Design Direction

The product aims for a **premium SaaS design aesthetic** rather than default Material UI.

Design principles:
- Minimal
- Typography-driven hierarchy
- Generous whitespace
- Soft rounded corners
- Layered cards
- Strategic use of primary color

Color palette:
- Primary: `#70020f`
- Background: `#fafafa`
- Surfaces: white

Visual inspiration:
- Linear
- Stripe
- Notion
